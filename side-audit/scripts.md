## Interpretation

The two-actor freeze demo is mixed, not purely client-side: it creates server-side scene actors before manipulating client animation. Most cursed examples also include fades or speech; a server-facing effect may be rendered by the client without constituting a separate client implementation. The multiplayer avatar example is a separate symmetric UDP experiment from the native KotorPhasor split-process transport. Its ghost template has host-level test evidence; this audit does not establish live or multiplayer acceptance.

The machine-readable inventory includes hashes, all explicitly named Lua function definitions, registered global callback definitions, public API references, and native routine string literals. It does not mistake event names in comments for implemented callbacks.

## Built-in engine console commands

`lua status` reports process-local host/runtime state. `lua reload` reloads local Lua states (callbacks may affect either side). `lua exec <code>` executes console Lua in the injected process; its API calls determine engine side. `lua` or unknown lua arguments print help. Entry is the client console seam, not a remote server evaluator.
