# prior-art

External-research map for a headless in-process KOTOR harness, gathered via direct fetches (curl) of primary sources, Wine source mirror, local man pages, developer/arXiv indexes; Firecrawl web search was out of credits (402) and Bing/Brave were bot-blocked, so several KOTOR folklore facts remain unconfirmed. Control-plane prior art converges on one shape: a socket listener on a helper thread that queues commands and executes them on the game thread at a fixed hook point (Phasor PhasorThread main/aux event queues; RetroArch UDP commands processed at vsync; AltTester WebSocket on 127.0.0.1:13000; Unreal Remote Control PUT remote/object/call JSON; Factorio RCON + /silent-command Lua; OpenMW runs Lua tests in-engine and the Python runner parses TEST_START/TEST_OK/TEST_FAILED stdout lines plus a 'Quit requested' sentinel). Wine facts: ws2_32 maps AF_INET to host BSD sockets so a listen() on 127.0.0.1 inside the 32-bit game DLL is a real Linux TCP socket; explorer /desktop=name,WxH is parsed in programs/explorer/desktop.c; unhandled exceptions print 'wine: Unhandled ... starting debugger...' to stderr and auto-launch 'winedbg --auto' (AeDebug Auto defaults TRUE), giving a stderr crash oracle; winedbg --gdb/--no-start/--command 'info proc' and 'attach N' cover hang diagnosis; Xvfb -screen + LIBGL_ALWAYS_SOFTWARE/GALLIUM_DRIVER=llvmpipe/LP_NUM_THREADS + ImageMagick 'import -window root' cover headless rendering and screenshots; KOTOR is confirmed OpenGL so in-process capture means glReadPixels, not D3D. KOTOR facts: EnableCheats=1 and Disable Movies=1 under [Game Options]; FullScreen/AllowWindowedMode/Width/Height/RefreshRate/Frame Buffer/Disable Vertex Buffer Objects under [Graphics Options]; full console command tables for K1 and K2 from StrategyWiki (K1-only whereami/dancedancemalak/givesitharmour, K2-only dance_dance_revan; 'setalign' not found); saves are per-folder savegame.sav + partytable.res + savenfo.res + GLOBALVARS.res; K2 Linux uses $XDG_DATA_HOME/aspyr-media/kotor2/ (PCGW) though Aspyr's FAQ prints a different folder name. No documented swkotor.exe command-line switches were found. Softlock literature: Go-Explore reachability testing, curiosity-driven coverage (EA), CCPT, Inspector, BiFuzz stuck detection, Wuji, ICARUS; no published Aurora/Odyssey DLG reachability analysis, but the DLG link struct (Active/Active2/Logic/Not/Index/IsChild) is documented and sufficient to build one. Tesseract: 300 dpi, ~30 px capital height sweet spot, dark-on-light for 4.x+ (invert KOTOR UI), 10 px border, --psm 6/7/11, --oem 1, dictionary off / char whitelist.

## Implications
- Control plane shape backed by prior art: a helper thread inside the binkw32 proxy DLL owns a 127.0.0.1 TCP listener (works under Wine because ws2_32 maps to host AF_INET sockets) and pushes parsed commands into a queue; the existing MainLoop hook drains the queue on the game thread and writes replies keyed by request id; events (RunScript, DoConsole, EventHandlers, save/load) stream back on the same connection. This is exactly Phasor's mainEvents/auxEvents split and RetroArch's process-at-vsync rule.
- Wire protocol: newline-delimited JSON with {id, cmd, args} / {id, ok, result} plus {event, ...} frames; keep GET_STATUS-style one-line liveness (module, tick, position, dialog node, load state) so the driver can poll cheaply; length-prefixed framing (Phasor) is the alternative if binary payloads (screenshots) are sent in-band.
- Crash oracle: launch with WINEDEBUG=+seh,+loaddll,+timestamp, capture stderr, and treat 'wine: Unhandled' / 'starting debugger...' as a hard failure; leave AeDebug Auto at default so 'winedbg --auto' prints a backtrace into the same log; optionally set AeDebug Debugger to 'winedbg --minidump' to keep .mdmp artifacts.
- Hang oracle: the MainLoop hook increments a tick counter exposed by the status command; the driver watches for a stale counter (no advance in N seconds while not loading) and then runs 'winedbg --command "info proc"' to find the wpid and 'winedbg --gdb --no-start <wpid>' (or gdb -p on the unix pid) to dump all thread stacks before killing.
- Headless rendering recipe: Xvfb :N -screen 0 1024x768x24; LIBGL_ALWAYS_SOFTWARE=1 GALLIUM_DRIVER=llvmpipe LP_NUM_THREADS=<small> (low-memory host); wine explorer /desktop=kp,1024x768 swkotor.exe; ini: [Graphics Options] FullScreen=0, AllowWindowedMode=1, Width=1024, Height=768, Frame Buffer=0, 'Disable Vertex Buffer Objects=1'; [Game Options] EnableCheats=1, Disable Movies=1. Periodic sanity screenshots via 'import -window root -display :N'; in-process capture must be glReadPixels after the game's SwapBuffers (OpenGL confirmed), not any D3D path.
- Plot jumping without keypresses: implement 'warp <module>', 'giveitem', 'addexp', 'setXXX' etc. by invoking the same engine routines the DoConsole hook reaches, or by feeding the console string into the hooked DoConsole handler on the game thread; the K1/K2 command tables above define the minimum verb set the harness must expose, and 'whereami' is K1-only so position must come from the engine bridge in K2.
- Checkpointing: use the game's own save folders (savegame.sav + partytable.res + savenfo.res + GLOBALVARS.res per subfolder) as Go-Explore-style checkpoints; the driver copies folders in/out of <game>/saves (K1/K2 Windows) or $XDG_DATA_HOME/aspyr-media/kotor2/saves (K2 Linux, verify exact folder name on disk) and triggers load through the hooked load path.
- Softlock detection stack (from the literature): (a) state-hash stagnation over {module, party position quantized, active dialog node, global booleans/numbers, quest states}; (b) progress oracle = expected plot-point sequence from a test script; (c) static DLG reachability: build graph from StartingList/EntriesList/RepliesList using Active/Active2 (+Logic/Not for TSL) as guards and evaluate guards against current globals via the RunScript bridge to know which replies are currently selectable; (d) watchdog on tick counter + load screens; (e) BiFuzz-style path mutation from checkpoints for stuck-in-geometry cases.
- OCR cross-check: crop the dialog/reply region, invert (light text on dark), upscale to ~30 px capital height (roughly 2-3x at 1024x768), optional Sauvola thresholding, 10 px border, run tesseract --oem 1 --psm 6 (block) or 7 (single reply line) with load_system_dawg=false load_freq_dawg=false; compare fuzzily against the TLK string the engine reports for the node instead of trusting OCR alone.
- Test-runner protocol: copy OpenMW's approach — in-game Lua test scripts emit TEST_START/TEST_OK/TEST_FAILED sentinel lines over the socket or log, the Python runner reports 'unexpected termination' when the quit sentinel never arrives, records the exit code, and copies logs per suite.
- K2 native Linux build: config and saves live under XDG paths, so the driver must parametrize save-dir per target (Wine prefix path vs $XDG_DATA_HOME); Aspyr FAQ and PCGamingWiki disagree on the folder name, so discover it by listing $XDG_DATA_HOME/aspyr-media at runtime rather than hardcoding.

## Risks
- General web search was mostly unavailable (Firecrawl 402, Bing unparsable, Brave bot-blocked after a few queries); several KOTOR folklore items (Autopause ini keys, screen.tga, K2 invisible console, native kotor2 binary launch env) are unconfirmed and should be verified on disk before being designed around.
- The kotor-modding.fandom.com DLG page was only readable through the MediaWiki API; if that endpoint changes, the DLG field list should be re-derived from PyKotor's DLG reader (allowed source) rather than the forbidden engines.
- Wine on this host is 11.0 Staging with i386-unix ntdll.so present under /usr/lib/wine-wow64; whether 32-bit processes run as 32-bit unix processes (classic) or inside a 64-bit host (new WoW64) was not settled, and it changes how gdb -p / winedbg attach behave.
- Xvfb GLX for a 32-bit Wine GL client depends on the i686 Mesa swrast DRI package being present (it is, mesa-dri-drivers.i686 26.1.8) — a missing i686 Mesa would produce a silent black window rather than an error.
- llvmpipe on a low-memory host: LP_NUM_THREADS defaults to all cores; leaving it unset can starve the game thread and produce false hang detections.
- 'restartminigame' is documented as crash-prone in K1 (swoop racing, Ebon Hawk turret) — exclude it from automated plot-jump verbs or expect crashes.
- Two sources disagree on the console key (` vs '); a driver must never rely on keypresses anyway, so route console commands through the DoConsole hook.
- Aspyr FAQ vs PCGamingWiki disagree on the K2 Linux save folder name; hardcoding either may miss the real directory.
- Saves written after any cheat carry a 'Cheat Used' watermark; if the harness reuses saves for human-facing repro, that marker will be present.
