# Native scene candidates

The explicit [catalog](catalog.json) lists authored native scale and animation
candidates. This curation change promotes none to featured: review each exact
scene/configuration and its independently measured recording before publishing.
A configured bow or victory run does not validate the stock dance script.

The original41 inventory includes developer tools, operator recipes, networking
experiments and regression fixtures. It is not a public gallery. Eight weak
public examples were physically retired into internal fixtures; see
[example validation](../../docs/example-validation.md). Useful diagnostics and
operator recipes remain available in scripts/examples for the bounded first
migration, without being advertised as visual showcases.
